**Trigger**
En tant que designer senior, on souhaite transmettre une documentation complète avec tous les éléments nécessaires aux développements d'une fonctionnalité.

**Commands / Instructions**
Analyse les maquettes et les sources du cadrage pour construire une documentation Handoff de la fonctionnalité.

**Output**
Document qui présente le contexte, identifie le DS utilisé, spécifie les parcours et les edge cases…

**Exigence**
N'invente rien. Réponds en 300 mots maximum.
